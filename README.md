# 📊 Data Visualization Practice with Python

## Overview

This repository contains my Data Visualization practice notebooks created using Python, Matplotlib, and Seaborn. The goal of this repository is to strengthen my data visualization and exploratory data analysis (EDA) skills by creating different types of charts and understanding how to present data effectively.

As an aspiring Data Analyst, I use this repository to practice visualizing datasets, identifying patterns, and communicating insights through charts and graphs.
